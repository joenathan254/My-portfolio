FINAL-YEAR PROJECT · FLAGSHIP

      
Jonathan's Farm Management System

      
A role-based web application that replaces a farm's paper notebooks with one centralized system running on the local network — built for a site with limited internet. One dashboard shows revenue, orders, customers and product counts, with live charts for the sales trend and payment methods.
